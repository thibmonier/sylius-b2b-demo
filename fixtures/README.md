# Demo Fixtures — Load Order

This document records all fixture names and their explicit priorities so that the load order is transparent and conflicts are easy to spot.

> SyliusFixturesBundle uses `SORT_DESC` on priorities. **Higher number = loaded first.**
> The built-in Sylius fixtures (channels, locales, currencies, …) have `priority: 0` (the default).
> All demo fixtures use **negative** priorities so they run after the built-in ones.

## Rules

- Each priority must be **unique** or the two fixtures must be truly independent (no data dependency between them).
  Fixtures at the same priority are executed in non-deterministic order relative to each other within that priority group.
- When adding a new fixture, check this table first to avoid conflicts.
- Fixture names must match the value returned by `getName()` exactly.
