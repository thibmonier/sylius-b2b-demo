# US-014 — Page d'accueil B2B et page Plugins

> Epic : [EPIC-03](../epics/EPIC-03.md) · Persona : Hugo · MoSCoW : **Must** · Points : **5** · Sprint : 4
> Dépendances : US-013

## Story

En tant que Hugo, je veux une page d'accueil et une page qui présente chaque plugin avec son scénario, afin de savoir quoi essayer.

## Valeur

Guide la visite.

## Critères d'acceptation

```gherkin
Fonctionnalité: Page d'accueil B2B et page Plugins

  Scénario: Page Plugins (nominal)
    Quand j'ouvre la page Plugins
    Alors chaque plugin (21 + nouveaux) a une carte : description, scénario, compte conseillé, lien GitHub et Packagist

  Scénario: Page d'accueil (alternatif)
    Quand j'ouvre la page d'accueil sur le canal B2B
    Alors je vois une accroche B2B, au moins 3 parcours de démo suggérés et un lien vers la page Plugins

  Scénario: Page Plugins en anglais (alternatif)
    Quand j'ouvre la page Plugins avec la locale « en »
    Alors les descriptions et scénarios sont affichés en anglais

  Scénario: Plugin sans dépôt publié (erreur)
    Quand un plugin du registre n'a pas de lien Packagist
    Alors sa carte n'affiche pas de lien cassé et indique « Non publié »

  Scénario: Registre invalide (erreur)
    Quand une entrée du registre des plugins n'a pas de description ou de compte conseillé
    Alors un test automatisé échoue en CI avec le nom du plugin fautif
```

## Definition of Done

- [ ] Critères d'acceptation automatisés (tests fonctionnels ou de fumée) et verts
- [ ] ECS, PHPStan (code de la démo et des nouveaux plugins)
- [ ] Libellés en français et en anglais si interface
- [ ] Aucun secret ni identifiant réel dans le dépôt
- [ ] Documentation mise à jour si comportement visible
- [ ] CI verte
