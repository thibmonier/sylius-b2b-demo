# US-182 — Garde : les `code` des tableaux de la démo se coupent à toutes les largeurs

> Epic : [EPIC-12](../epics/EPIC-12.md) · Persona : Camille (recruteuse IT) sur téléphone · MoSCoW : **Should** · Points : **1** · Sprint : backlog
> Origine : action 2 de la rétrospective du sprint 25 (débordement de la page des packs en production, corrigé par #80)

## Story

En tant que visiteuse sur téléphone, je veux que les tableaux des pages de la démo tiennent dans l'écran, afin de lire une page sans défilement horizontal.

## Contexte

Bootstrap donne aux `code` la règle `word-wrap: break-word`, qui l'emporte sur le `overflow-wrap: anywhere` hérité d'une cellule. Avec des valeurs réelles longues (noms de classes), la page des packs faisait 645 px de large à 360 px et 2105 px à 1280 px. Les tests fonctionnels, qui lisent le HTML, et pa11y, qui ne mesure pas la largeur, ne l'ont pas vu.

## Critères d'acceptation

```gherkin
Fonctionnalité: Garde contre le débordement des tableaux

  Scénario: Page conforme (nominal)
    Étant donné une page de templates/demo dont un tableau contient du code
    Quand la garde s'exécute
    Alors elle trouve, hors media query, une règle overflow-wrap: anywhere qui s'applique à ces code

  Scénario: Tableau sans code (alternatif)
    Étant donné une page dont les tableaux ne contiennent pas de code
    Quand la garde s'exécute
    Alors la page n'est pas concernée

  Scénario: Règle globale (alternatif)
    Étant donné une règle commune à toutes les pages de la démo qui couvre les code des tableaux
    Quand la garde s'exécute
    Alors les pages qui en héritent sont conformes

  Scénario: Règle absente (erreur)
    Étant donné une page dont un tableau contient du code sans la règle
    Quand la garde s'exécute
    Alors elle échoue en nommant le gabarit

  Scénario: Règle seulement sur mobile (erreur)
    Étant donné une règle placée uniquement dans une media query
    Quand la garde s'exécute
    Alors elle échoue, car le débordement existe aussi à 1280 px
```
