# US-035 — Admin de démo restreint

> Epic : [EPIC-09](../epics/EPIC-09.md) · Persona : Sophie · MoSCoW : **Must** · Points : **8** · Sprint : 6
> Dépendances : US-009

## Story

En tant que Sophie, je veux un compte back-office public qui ne peut pas casser la démo, afin que chacun explore l'admin sans risque.

## Valeur

R3.

## Critères d'acceptation

```gherkin
Fonctionnalité: Admin de démo restreint

  Scénario: Lecture seule
    Étant donné Sophie connectée
    Quand elle tente de modifier les administrateurs, canaux, passerelles, URLs de webhooks ou clés
    Alors l'action est refusée avec un message de démo
    Et le reste de l'admin est utilisable

  Scénario: Reste de l'admin utilisable
    Étant donné Sophie connectée avec le rôle ROLE_DEMO_ADMIN
    Quand elle consulte les ressources sensibles et édite un produit ou une commande
    Alors la lecture et l'édition non sensible fonctionnent

  Scénario: Message de démo bilingue
    Étant donné une écriture sensible refusée
    Alors le message de démo s'affiche en français ou en anglais selon la locale (flash et page 403)

  Scénario: Compte public protégé
    Quand Sophie tente de changer son mot de passe, son e-mail ou de créer un jeton API
    Alors la demande est refusée et son mot de passe reste inchangé

  Scénario: Contournement par requête directe
    Quand Sophie envoie un POST direct avec un jeton CSRF valide, une surcharge _method ou une action de masse sur une ressource sensible
    Alors la requête est refusée

  Scénario: Route d'écriture non classée
    Étant donné une route d'écriture absente de la matrice des routes sensibles
    Quand Sophie l'appelle dans la zone sensible
    Alors elle est refusée par défaut

  Scénario: Contenu injecté
    Étant donné un contenu édité par Sophie contenant du script
    Quand une page de la boutique l'affiche
    Alors le script n'est pas exécuté (échappement ou nettoyage)
```

## Definition of Done

- [ ] Libellés en français et en anglais si interface
