# US-230 — Passeport numérique produit : squelette du plugin et modèle de données ouvert et versionné

> Epic : [EPIC-19](../epics/EPIC-19.md) · Persona : Sophie (back-office du marchand) · MoSCoW : **Must** · Points : **5** · Sprint : sprint 36 (proposé, décision de Thibaut du 2026-10-28) · Statut : **backlog**
> Dépendances : US-229

## Story

En tant que Sophie, je veux renseigner le passeport d'un produit dans l'admin, afin de constituer une base de données produit versionnée et exploitable.

## Contexte

Walking skeleton de `tmonier/sylius-digital-product-passport-plugin`. Modèle **ouvert et versionné** : un passeport par produit, avec un numéro de version de schéma et un historique des révisions. Champs : origine des matériaux, composition, recyclabilité, réparabilité (indice et instructions), garantie, **références de pièces détachées compatibles** (liens, voir US-233), documents. Export JSON du modèle (schéma publié). Aucune affirmation de conformité réglementaire (US-229).

Règles transverses de la feuille de route : voir [roadmap-innovation](../roadmap-innovation.md) (ton neutre, aucun détail de sécurité dans le dépôt public, aucune promesse réglementaire).

## Critères d'acceptation

```gherkin
Fonctionnalité: Passeport numérique produit : squelette du plugin et modèle de données ouvert et versionné

  Scénario: Passeport créé (nominal)
    Étant donné un produit sans passeport
    Quand Sophie en crée un dans l'admin
    Alors le passeport est enregistré en version 1 du schéma avec ses champs

  Scénario: Révision (alternatif)
    Étant donné un passeport existant
    Quand Sophie le modifie
    Alors une révision est conservée avec date et auteur

  Scénario: Export JSON (alternatif)
    Étant donné un passeport complet
    Quand l'export est demandé
    Alors le JSON respecte le schéma versionné publié

  Scénario: Champ obligatoire manquant (erreur)
    Étant donné un passeport sans origine des matériaux
    Quand Sophie le valide
    Alors une erreur nomme le champ

  Scénario: Version de schéma inconnue (erreur)
    Étant donné un passeport d'une version de schéma non gérée
    Quand il est chargé
    Alors il est refusé avec un message clair, sans corruption
```
