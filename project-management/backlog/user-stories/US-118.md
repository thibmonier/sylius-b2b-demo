## Story

En tant que Thibaut, je veux un gabarit de fiche et six fiches rédigées (PunchOut, devis, commande rapide, approbation, MCP, container-fill), afin de les mettre en ligne sur mon site sans réécrire.

## Contexte

Fiches prêtes à copier dans le site (Markdown + visuels), sur le gabarit : problème, solution, écran, scénario de démo, installation, liens (dépôt, Packagist, démo, contact). La mise en ligne est faite par Thibaut. Cohérence avec les README (même source de texte).
