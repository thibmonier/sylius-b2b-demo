# US-108 — Page « Intégrations » : ERP, PIM, transporteurs, e-facture, grands comptes, assistants

> Epic : [EPIC-12](../epics/EPIC-12.md) · Persona : Hugo · MoSCoW : **Should** · Points : **3** · Sprint : cible sprint 20 (replanifiée le 2026-10-21, repositionnement « recherche d'emploi »)
> Dépendances : audit fonctionnel §6.2.8 ; US-130 (P5)

## Story

En tant que Hugo (intégrateur), je veux un schéma des intégrations avec leur état (disponible, non fourni, en cours), afin de savoir ce qui existe déjà et ce qui reste à développer.

## Contexte

Le schéma relie ERP, PIM, transporteurs, PA/PDP, portails d'achat et assistants IA aux plugins concernés (webhook-outbox, punchout, facturx, b2b-mcp…). Les états sont issus de la même source que le statut des plugins (US-087).

> **Réécriture du 2026-10-21 (guide technique, pas de sollicitation commerciale).** L'état « sur mesure » devient « non fourni » : la page décrit, elle ne propose pas de prestation. Pas de bouton de contact ; le pied de page porte le CTA neutre d'US-158.

## Critères d'acceptation

```gherkin
Fonctionnalité: Page « Intégrations » : ERP, PIM, transporteurs, e-facture, grands comptes, assistants

  Scénario: Schéma lisible (nominal)
    Étant donné la page ouverte
    Quand Didier la lit
    Alors chaque intégration porte un état et renvoie vers le plugin

  Scénario: Plugin en cours (alternatif)
    Étant donné un plugin non publié
    Quand la page est affichée
    Alors l'état est « à venir » ou « en cours »

  Scénario: Intégration non fournie (alternatif)
    Étant donné une intégration sans plugin (ex. un ERP donné)
    Quand la page est affichée
    Alors l'état est « non fourni » et la page renvoie vers le contrat d'événements du plugin webhook-outbox

  Scénario: État incohérent (erreur)
    Étant donné un plugin publié marqué à venir
    Quand le contrôle de cohérence s'exécute
    Alors il échoue

  Scénario: Formulation commerciale (erreur)
    Étant donné un texte contenant « sur mesure », « devis » ou « nous développons pour vous »
    Quand le contrôle de charte s'exécute
    Alors il échoue
```
