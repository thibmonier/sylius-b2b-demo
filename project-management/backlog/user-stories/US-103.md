# US-103 — Assistants IA : page utile avec transcript d'une vraie conversation

> Epic : [EPIC-11](../epics/EPIC-11.md) · Persona : Nadia · MoSCoW : **Should** · Points : **3** · Sprint : sprint 18, solde au sprint 23 (plan du 2026-10-23 ; conditionnée au transcript T-103-03)
> Dépendances : audit fonctionnel D8 (top 10 n°7) ; US-030, US-043 ; enregistrement par Thibaut

## Story

En tant que Nadia, je veux voir ce qu'un assistant fait réellement avec la démo (transcript et courte vidéo), afin de comprendre le bénéfice sans configurer d'assistant.

## Contexte

La page « Assistants IA » affiche « Aucun assistant connecté ». Thibaut réalise une vraie conversation (action externe) ; Claude prépare le script, la page et le transcript relu, avec le rappel que l'assistant ne paie jamais. L'URL MCP affichée doit être celle de production (jamais `localhost`).

## Critères d'acceptation

```gherkin
Fonctionnalité: Assistants IA : page utile avec transcript d'une vraie conversation

  Scénario: Transcript visible (nominal)
    Étant donné la page Assistants IA
    Quand Nadia l'ouvre
    Alors elle lit un transcript de 4 à 6 échanges réels, daté, et voit la vidéo ou le GIF

  Scénario: URL de production (alternatif)
    Étant donné l'environnement de production
    Quand la page affiche l'adresse MCP
    Alors elle est celle du site public

  Scénario: Transcript sans vidéo (alternatif)
    Étant donné un transcript fourni sans vidéo ni GIF
    Quand Nadia ouvre la page
    Alors le transcript est affiché seul, sans lecteur vide ni lien cassé, et la page reste sans débordement à 320 px

  Scénario: Conversation non réalisée (erreur)
    Étant donné aucun enregistrement fourni
    Quand la page est affichée
    Alors le bloc transcript est masqué et le guide existant reste visible

  Scénario: Donnée sensible dans le transcript (erreur)
    Étant donné un transcript contenant un jeton d'accès, une adresse e-mail ou une URL locale (localhost)
    Quand le contrôle du fichier de transcript s'exécute
    Alors le transcript est refusé en nommant la ligne et le motif, et n'est pas affiché
```
