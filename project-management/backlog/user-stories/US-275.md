# US-275 — Serveur MCP de Sylius 0.3 : plugin b2b-mcp puis démo

> Epic : [EPIC-10](../epics/EPIC-10.md) · Persona : Thibaut ; Didier (DSI) · MoSCoW : **Should** · Points : **3** · Sprint : sprint 52 (planifié le 2026-11-10) · Statut : **ready-for-dev**
> Origine : veille des versions de la semaine 46 (#178), montée majeure bloquée par une contrainte.

## Story

En tant que Thibaut, je veux que la démo et le plugin b2b-mcp tournent sur `sylius/mcp-server-plugin` 0.3, afin que l'outillage MCP présenté dans la démo suive le serveur officiel de Sylius.

## Contexte

- La démo et `tmonier/sylius-b2b-mcp-plugin` (v1.2.3) requièrent `sylius/mcp-server-plugin ^0.2`. La 0.3 requiert `symfony/mcp-bundle ^0.13` (0.2 utilisait une version bien plus ancienne).
- Notes de version de la 0.3 : montées successives de `symfony/mcp-bundle` (0.5, 0.9, 0.13 avec plusieurs serveurs) et **point d'entrée renommé de `/_mcp` en `/mcp/shop`** dans le README.
- La démo référence le point d'entrée dans sa configuration (`config/routes/sylius_mcp_server.yaml`, `config/packages/demo_hardening.yaml`, `config/packages/demo_channel_access.yaml`), son guide MCP (`McpGuideController`) et `config/demo/*.yaml`.
- Ordre : plugin b2b-mcp (contrainte, adaptation à mcp-bundle 0.13, version taguée par Thibaut), puis démo. L'ampleur des changements de mcp-bundle est à mesurer en premier (T-275-01) ; si elle dépasse 3 points, la story est redécoupée avec Thibaut.
