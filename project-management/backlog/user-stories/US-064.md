# US-064 — Bloc standard, outil de contrôle et README FR du lot A (12 plugins)

> Epic : [EPIC-09](../epics/EPIC-09.md) · Persona : Thibaut · MoSCoW : **Must** · Points : **4** · Sprint : 13
> Dépendances : US-063 (charte de ton) ; suite : US-067 (lot B et livraison)

## Story

En tant que Thibaut, je veux un bloc standard identique (FR et EN) qui renvoie à la démo B2B, un `README.fr.md` pour chaque plugin et un lien croisé en tête des deux README, afin que les 24 plugins soient lisibles en français et en anglais et fassent tous référence à la démo.

## Contexte

Les 24 dépôts `sylius-*-plugin` sont publics et aucun n'a de `README.fr.md`. Décision D1 : on publie sans le site ; le bloc ne contient donc **aucun** lien vers le site ni la page de contact (US-068). Tant que la démo est privée, le lien pointe vers le dépôt public `https://github.com/thibmonier/sylius-b2b-demo` ; l'URL en ligne est ajoutée à la bascule. Tous les plugins renvoient à la démo, y compris `sylius-customer-asset-management-plugin`, absent de la démo (le bloc le dit). Le README anglais reste la référence.

**Option de livraison proposée (à valider par l'utilisateur)** :

- **A (recommandée)** : une branche `docs/readme-fr-demo` et une PR par dépôt (règle 09), 24 PR ouvertes en un lot, **un seul GO de merge pour le lot**, merge squash. Contre : la CI de beaucoup de plugins ignore les `*.md` (`paths-ignore`) ; si la protection de branche exige un contrôle, il restera « en attente » et le merge demandera l'accord de l'utilisateur. Pour: règle respectée, relecture possible, retour arrière simple.
- **B** : commit direct sur `main` (exception documentée à la règle 09 pour des fichiers `*.md` uniquement, sans code). Plus rapide, aucune relecture ; réservé à l'accord explicite de l'utilisateur.

## Périmètre

- Texte du bloc standard EN et FR (démo, dépôt public, avertissement « démo à l'état d'exemple », mention « non présent dans la démo » si besoin), ton selon la charte d'US-063.
- Outil `bin/vitrine-readme` dans la démo (pas dans les plugins) : applique le bloc et les liens croisés de façon idempotente à un dépôt donné, vérifie les 24 ; mode `--check` en lecture seule.
- `README.fr.md` des 12 premiers plugins (lot A, par ordre alphabétique : de `admin-order-creation` à `facturx`), même structure que l'anglais (titres, tableaux, blocs de code intacts, liens).
- Lien `Français : README.fr.md` en tête du README anglais, `English: README.md` en tête du français.
- Hors périmètre : lot B (US-067), images (US-065), liens vers le site et la page contact (US-068), tout push et tout merge sans GO.

## Critères d'acceptation

```gherkin
Fonctionnalité: Bloc standard et README FR (lot A)

  Scénario: Un plugin du lot A reçoit son README FR et le bloc (nominal)
    Étant donné un dépôt du lot A à jour sur main
    Quand bin/vitrine-readme est appliqué sur une branche locale
    Alors README.fr.md existe avec la même structure de titres que README.md
    Et le bloc standard figure en EN dans README.md et en FR dans README.fr.md
    Et chaque README a en tête un lien vers l'autre langue

  Scénario: L'outil est idempotent (alternatif)
    Étant donné un dépôt déjà traité
    Quand l'outil est relancé
    Alors aucun fichier ne change

  Scénario: Les blocs de code et les identifiants restent intacts (alternatif)
    Étant donné un README contenant des commandes, des noms de classes et des tableaux de configuration
    Quand la version française est contrôlée
    Alors les blocs de code, les noms de classes, de routes et de variables sont identiques à l'anglais

  Scénario: Le plugin n'est pas dans la démo (erreur)
    Étant donné sylius-customer-asset-management-plugin
    Quand le bloc est appliqué
    Alors il indique que le plugin n'est pas encore intégré à la démo
    Et il ne promet aucune page ni aucune donnée de démo

  Scénario: Un lien vers le site ou une comparaison avec Plus s'est glissé dans le texte (erreur)
    Étant donné un README traité
    Quand bin/vitrine-readme --check est lancé
    Alors il échoue en nommant le fichier et la ligne (lien hors démo, ou terme interdit par la charte)
```
