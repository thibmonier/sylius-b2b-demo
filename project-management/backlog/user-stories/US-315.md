# US-315 — Plugins : traiter les PR Dependabot ouvertes (phpunit, GitHub Actions)

> Epic : [EPIC-01](../epics/EPIC-01.md) · Persona : Thibaut (mainteneur des plugins) · MoSCoW : **Should** · Points : **3** · Sprint : à planifier · Statut : **backlog**
> Origine : demande de Thibaut du 2026-11-23. Les PR Dependabot de la démo passent par T-TECH-57-06 (sprint 57) ; celles des autres plugins attendent cette story, hors sprint 57.
> Dépendances : aucune. À faire de préférence avec [US-314](US-314.md) (mêmes dépôts, même fichier de CI pour les actions).

## Story

En tant que mainteneur des plugins, je veux que les PR Dependabot ouvertes sur les plugins soient fusionnées ou fermées avec une raison, afin que leurs dépendances de développement et de CI restent à jour sans casser la matrice PHP 8.2 à 8.5.

## Contexte

Relevé du 2026-11-23, 8 PR dans 7 plugins :

| Dépôt | PR | Mise à jour | CI au relevé |
|-------|----|-------------|--------------|
| sylius-company-accounts-plugin | #11 | phpunit `^10.5` → `^12.5` | 1 échec |
| sylius-facturx-plugin | #12 | phpunit `^10.5` → `^12.5` | 1 échec |
| sylius-quick-order-plugin | #12 | phpunit `^10.5` → `^12.5` | à relever |
| sylius-order-hold-plugin | #6 | phpunit `^10.5` → `^13.4` | à relever |
| sylius-digital-product-passport-plugin | #21 | phpunit `^10.5` → `^13.4` | à relever |
| sylius-platform-health-plugin | #3 | phpunit `^10.5` → `^13.4` | 4 échecs |
| sylius-facturx-plugin | #14 | actions/setup-java 6.1.0 → 6.2.0 | à relever |
| sylius-b2b-predictive-analytics-plugin | #15 | actions/github-script 7.0.1 → 9.0.0 (majeure) | à relever |

- **Cause probable des échecs phpunit** : Dependabot *remplace* la contrainte. Les plugins déclarent `php: ^8.2`, alors que PHPUnit 12 exige PHP 8.3 et PHPUnit 13 exige PHP 8.4 : les jobs PHP 8.2 (et 8.3 pour `^13.4`) ne peuvent plus installer. Le correctif attendu est d'*élargir* la contrainte (par exemple `^10.5 || ^11.5 || ^12.5 || ^13.4`) dans une PR à soi, puis de fermer celle de Dependabot avec un renvoi. Il faut vérifier que les tests n'utilisent pas d'API retirée entre ces versions (annotations `@test`, `@dataProvider` en docblock).
- **Actions** : `setup-java` est une mineure ; `github-script` 9 est une majeure, il faut lire ses notes de version (version de Node, API `github`) avant de fusionner.
- Hors périmètre : la démo (T-TECH-57-06) et les dépôts hors `sylius-*`.

## Critères d'acceptation

```gherkin
Fonctionnalité: PR Dependabot des plugins traitées

  Scénario: Contrainte phpunit élargie (nominal)
    Étant donné un plugin qui déclare php ^8.2 et une PR Dependabot phpunit ^10.5 → ^13.4
    Quand la contrainte est élargie à toutes les versions compatibles
    Alors la matrice CI complète (PHP 8.2 à 8.5) est verte
    Et la PR Dependabot est fermée avec un lien vers la PR qui la remplace

  Scénario: Mise à jour d'action mineure (alternatif)
    Étant donné la PR actions/setup-java 6.1.0 → 6.2.0
    Quand sa CI est verte et zizmor sans nouveau constat
    Alors elle est proposée à la fusion telle quelle

  Scénario: Mise à jour d'action majeure (alternatif)
    Étant donné la PR actions/github-script 7 → 9
    Quand ses notes de version ont été lues et les scripts du workflow vérifiés
    Alors la PR est proposée à la fusion avec le résultat de cette lecture

  Scénario: Une PR reste rouge après élargissement (erreur)
    Étant donné un plugin dont les tests échouent sous une version de PHPUnit
    Quand l'échec vient d'une API retirée
    Alors les tests sont adaptés dans la même PR, ou la version est exclue de la contrainte avec la raison écrite dans la PR

  Scénario: Dependabot rouvre une PR fermée (erreur)
    Étant donné une PR Dependabot fermée parce qu'elle a été remplacée
    Quand Dependabot en propose une nouvelle pour la même contrainte
    Alors la nouvelle est fermée avec le même renvoi, ou une règle ignore est ajoutée à dependabot.yml
```

## Definition of Done

- [ ] Les 8 PR fusionnées, ou fermées avec un renvoi ou une raison
- [ ] CI verte sur toute la matrice pour chaque dépôt modifié, zizmor sans nouveau constat
- [ ] Aucune version de plugin nécessaire (dépendances de dev et CI seulement), sauf si un changement touche `require`
- [ ] Liste des PR et de leur état tenue dans la fiche
