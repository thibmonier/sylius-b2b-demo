# US-279 — Thème Industrie & Négoce : script du mode sombre compatible avec une CSP stricte

> Epic : [EPIC-18](../epics/EPIC-18.md) · Persona : Hugo (intégrateur Sylius) · MoSCoW : **Should** · Points : **2** · Sprint : sprint 53 (proposé le 2026-11-11) · Statut : **ready-for-dev**
> Origine : revue du sprint 52 ; le README de la v0.2.0 demande à l'intégrateur d'autoriser lui-même le script.

## Story

En tant qu'Hugo, je veux installer le thème sur une boutique qui interdit les scripts en ligne (CSP sans `'unsafe-inline'`), afin de garder le mode sombre sans affaiblir la politique de sécurité du client.

## Contexte

- Le mode sombre repose sur un petit script en ligne dans le `<head>` (`<script data-industry-color-mode>`), nécessaire pour appliquer le choix avant le premier rendu. Une CSP stricte le bloque : le commutateur reste masqué et le choix mémorisé n'est pas appliqué.
- Le README de la v0.2.0 renvoie l'intégrateur au calcul d'un nonce ou d'une empreinte, sans valeur fournie.
- Sylius ne fournit pas de nonce CSP ; NelmioSecurityBundle en fournit un (`csp_nonce('script')`) quand il est installé.

## Critères d'acceptation

```gherkin
Fonctionnalité: Script du mode sombre sous CSP stricte

  Scénario: Empreinte publiée (nominal)
    Étant donné une CSP « script-src 'self' » complétée par l'empreinte SHA-256 publiée dans le README
    Quand la page d'un canal avec le thème se charge
    Alors le script s'exécute et le commutateur est visible

  Scénario: Nonce de l'application (alternatif)
    Étant donné une application qui fournit un nonce de script (NelmioSecurityBundle)
    Quand la page se charge
    Alors le script porte ce nonce

  Scénario: Sans CSP (alternatif)
    Étant donné une application sans CSP
    Quand la page se charge
    Alors le comportement est celui de la v0.2.0

  Scénario: Script modifié sans mettre l'empreinte à jour (erreur)
    Étant donné une modification du script du mode sombre
    Quand la CI du thème tourne
    Alors un test échoue en indiquant que l'empreinte du README ne correspond plus

  Scénario: Script bloqué (erreur)
    Étant donné une CSP stricte sans l'empreinte ni le nonce
    Quand la page se charge
    Alors la page reste en mode clair ou système, sans commutateur inutilisable affiché
```

## Definition of Done

- [ ] Nonce de l'application utilisé quand il existe, sans dépendance obligatoire à NelmioSecurityBundle
- [ ] Empreinte SHA-256 du script publiée dans les README FR/EN, vérifiée par un test (rouge prouvé en modifiant le script)
- [ ] CHANGELOG, CI verte
