# US-025 — Carnet d'adresses de l'entreprise

> Epic : [EPIC-06](../epics/EPIC-06.md) · Persona : Isabelle · MoSCoW : **Should** · Points : **8** · Sprint : 5
> Dépendances : US-009

## Story

En tant que Isabelle, je veux un carnet d'adresses partagé par les membres, afin que chacun livre sur les sites de l'entreprise.

## Critères d'acceptation

```gherkin
Fonctionnalité: Carnet d'adresses de l'entreprise

  Scénario: Adresses partagées
    Étant donné Isabelle qui ajoute l'adresse « Usine de Lyon »
    Quand Claire passe commande
    Alors elle peut choisir cette adresse de livraison
    Et seuls les administrateurs de l'entreprise la modifient

  Scénario: Consultation par un membre
    Quand Claire ouvre le carnet d'adresses
    Alors elle voit les adresses de l'entreprise sans action de modification

  Scénario: Compatibilité v1.1
    Étant donné une entreprise sans adresse partagée
    Quand un membre passe commande
    Alors le checkout se comporte comme en v1.1

  Scénario: Modification par un non-administrateur
    Quand Claire tente de modifier « Usine de Lyon »
    Alors l'accès est refusé

  Scénario: Adresse d'une autre entreprise
    Quand une adresse d'une autre entreprise est soumise au checkout
    Alors elle est rejetée

  Scénario: Adresse invalide
    Quand Isabelle enregistre une adresse sans code postal
    Alors une erreur de validation est affichée et rien n'est enregistré
```
