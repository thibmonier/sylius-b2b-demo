# US-193 — Commandes de démo passées pour un vrai extrait sur /echange-fichier

> Epic : [EPIC-14](../epics/EPIC-14.md) · Persona : lead développeur d'une agence · MoSCoW : **Should** · Points : **2** · Sprint : **sprint 27** ([tâches](../../sprints/sprint-27-fiche-produit-et-erp-fictif/tasks/US-193-tasks.md))
> Origine : suite d'[US-190](./US-190.md), validée par Thibaut le 2026-10-24

## Story

En tant que lead développeur d'une agence qui évalue la démo, je veux voir sur la page `/{locale}/echange-fichier` un extrait réel du fichier CSV produit par le plugin d'export en fichier plat, afin de juger le contrat sans installer le plugin.

## Contexte

La page d'US-190 présente les colonnes du contrat et un extrait. Cette story la fait lire un vrai fichier : les fixtures de démo passent quelques commandes (événements `order.placed` dans l'outbox du plugin `webhook-outbox`), un export est lancé au chargement des fixtures, et la page affiche l'en-tête et quelques lignes du dernier fichier produit.

Contraintes : données fictives seulement (adresses `*.example`), aucune donnée personnelle réelle ; les tests n'écrivent jamais hors du répertoire d'échange configuré.

### Validation INVEST

- [x] Independent (après US-190) / Negotiable / Valuable / Estimable ≈ 4 h / Sized 2 / Testable

## Critères d'acceptation

```gherkin
Fonctionnalité: Extrait réel du fichier plat

  Scénario: Extrait du dernier fichier (nominal)
    Étant donné des commandes de démo passées et un export lancé au chargement des fixtures
    Quand un visiteur ouvre la page d'échange de fichier
    Alors il voit l'en-tête et quelques lignes du dernier fichier produit

  Scénario: Aucun fichier encore produit (alternatif)
    Étant donné un répertoire d'échange sans fichier
    Quand la page est affichée
    Alors un message explicite indique qu'aucun fichier n'a encore été produit, sans erreur

  Scénario: Fichier produit pour l'autre canal (alternatif)
    Étant donné un fichier dont les commandes viennent de l'autre canal
    Quand la page est affichée
    Alors seules les lignes du canal courant sont montrées, ou un message neutre si aucune

  Scénario: Répertoire absent ou illisible (erreur)
    Étant donné un répertoire d'échange absent ou illisible
    Quand la page est affichée
    Alors la page répond 200 avec un message neutre, sans erreur 500 ni chemin interne

  Scénario: Fichier vide (erreur)
    Étant donné un fichier vide
    Quand la page est affichée
    Alors un message neutre remplace l'extrait, sans erreur
```
