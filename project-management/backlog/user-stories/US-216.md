# US-216 — Copilote d'achat : adaptateur LLM réel pour les intégrateurs

> Epic : [EPIC-16](../epics/EPIC-16.md) · Persona : Hugo (intégrateur Sylius) · MoSCoW : **Could** · Points : **5** · Sprint : 42 (planifiée par Thibaut le 2026-10-28) · Statut : **backlog**
> Dépendances : US-210, US-214

## Story

En tant qu'Hugo, intégrateur, je veux brancher mon fournisseur de LLM sur le copilote, afin de l'utiliser sur un vrai site sans le modifier.

## Contexte

Implémentation de l'adaptateur réel retenu au spike (US-210) derrière le port `CopilotModel` : configuration par variables d'environnement, délai d'attente, relances bornées, coût journalier plafonné, mode de bascule vers le rejoué en cas d'erreur. Non planifiée : déclenchée seulement si un intégrateur en exprime le besoin (YAGNI).

Règles transverses de la feuille de route : voir [roadmap-innovation](../roadmap-innovation.md) (ton neutre, aucun détail de sécurité dans le dépôt public, aucune promesse réglementaire).

## Critères d'acceptation

```gherkin
Fonctionnalité: Copilote d'achat : adaptateur LLM réel pour les intégrateurs

  Scénario: Appel réel réussi (nominal)
    Étant donné une clé d'API valide
    Quand l'acheteuse demande un réassort
    Alors l'adaptateur appelle le modèle et seuls les outils autorisés sont exécutés

  Scénario: Fournisseur alternatif (alternatif)
    Étant donné un autre fournisseur configuré
    Quand le plugin démarre
    Alors il utilise l'adaptateur correspondant sans autre changement

  Scénario: Bascule vers le rejoué (alternatif)
    Étant donné l'option de repli activée
    Quand le fournisseur est indisponible
    Alors la réponse enregistrée la plus proche est servie avec mention

  Scénario: Délai dépassé (erreur)
    Étant donné un délai de 10 s
    Quand le fournisseur ne répond pas
    Alors l'acheteuse voit un message d'indisponibilité et rien n'est modifié dans le panier

  Scénario: Plafond de coût atteint (erreur)
    Étant donné le plafond journalier atteint
    Quand une demande arrive
    Alors elle est refusée avec un message, sans appel facturé
```
