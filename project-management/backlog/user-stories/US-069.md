# US-069 — La page Plugins de la démo renvoie vers le site

> **RETIRÉE le 2026-10-21 (repositionnement « recherche d'emploi »).** Absorbée par US-158 : le CTA neutre vers le profil LinkedIn couvre toutes les pages, dont la page Plugins ; le site n'existe pas. Fiche conservée pour l'historique ; ne plus planifier.

> Dépendances : URL du site et de la page contact ; US-014 (page Plugins) ; US-066 (sous-domaine)

## Story

En tant que Thibaut, je veux que la page Plugins de la démo renvoie vers la liste de mes plugins sur mon site et vers la page « me contacter », afin que les visiteurs de la démo trouvent mes missions.

## Contexte

La page Plugins (US-014) liste les plugins de la démo avec leur dépôt. Les liens vers le site sont reportés à cause de l'URL inconnue (décision D1). Les URL sont des paramètres de configuration, pas des valeurs codées en dur ; le ton suit la charte d'US-063 (aucune comparaison avec Plus).

## Critères d'acceptation

```gherkin
Fonctionnalité: Liens vers le site depuis la page Plugins

  Scénario: La page affiche les deux liens (nominal)
    Étant donné les URL configurées
    Quand le visiteur ouvre la page Plugins en FR ou en EN
    Alors il voit un lien vers la liste des plugins du site et un lien vers la page contact

  Scénario: Les URL ne sont pas configurées (alternatif)
    Étant donné aucune URL
    Quand la page est affichée
    Alors le bloc est masqué sans erreur

  Scénario: Une URL non https est configurée (erreur)
    Étant donné une URL en http ou avec un schéma inattendu
    Quand la configuration est chargée
    Alors elle est refusée et le bloc reste masqué
```
