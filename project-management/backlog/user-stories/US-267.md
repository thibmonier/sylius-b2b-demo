# US-267 — Chaîne de build du thème industrie : Webpack Encore 7 et Babel 8

> Epic : [EPIC-10](../epics/EPIC-10.md) · Persona : Thibaut · MoSCoW : **Should** · Points : **3** · Sprint : à planifier (quand Sylius aura migré) · Statut : **backlog**
> Origine : veille des versions du 2026-11-03 (7 PR Dependabot npm majeures sur `sylius-industry-trade-theme`, fermées)

## Story

En tant que Thibaut, je veux monter en un seul lot la chaîne de build du thème industrie, afin qu'il reste au niveau de la démo sans risquer une construction cassée à moitié.

## Contexte

Le 2026-10-28, Dependabot a ouvert 7 montées majeures indépendantes sur le thème : `@symfony/webpack-encore` 4 → 7, `webpack-cli` 5 → 7, `@babel/core` et `@babel/preset-env` 7 → 8, `babel-loader` 9 → 10, `sass-loader` 14 → 17, `@symfony/stimulus-bridge` 3 → 4. Ces paquets dépendent les uns des autres : les merger un par un produit des états intermédiaires incohérents, même si chaque PR est verte (le CI ne construit pas forcément toutes les combinaisons). La démo est déjà sur Encore 6 et voit Encore 7 et stimulus-bridge 4 dans sa veille.

Décision de Thibaut du 2026-11-04 : la chaîne de build du thème est **ignorée pour le moment** (`@dependabot ignore this dependency` sur Encore, webpack-cli, sass-loader et les paquets Babel ; Dependabot proposait sinon la majeure précédente, Encore 6, webpack-cli 6, sass-loader 16). Elle reviendra **quand Sylius aura migré** sa propre chaîne de build.

## Critères d'acceptation

```gherkin
Fonctionnalité: Chaîne de build du thème à jour

  Scénario: Build complet (nominal)
    Étant donné le thème avec les 7 paquets à leur dernière majeure
    Quand le CI construit les assets
    Alors le build réussit et les fichiers produits sont chargés par la démo

  Scénario: Rendu inchangé (alternatif)
    Étant donné la démo avec le thème mis à jour
    Quand on capture la page d'accueil, une fiche produit et le panier
    Alors les captures sont identiques à celles d'avant la montée

  Scénario: Contrôleurs Stimulus (alternatif)
    Quand un contrôleur Stimulus du thème est utilisé (menu, quantités)
    Alors il réagit comme avant

  Scénario: Option retirée (erreur)
    Étant donné une option de configuration Encore ou Babel retirée en v7/v8
    Quand le build échoue
    Alors la configuration est migrée, sans épingler l'ancienne version

  Scénario: Avertissements (erreur évitée)
    Quand le build tourne
    Alors aucun avertissement de dépréciation de la chaîne n'apparaît
```

## Definition of Done

- [ ] Une seule PR sur le thème, CI vert
- [ ] Captures avant/après dans la démo
- [ ] Dependabot groupe désormais les mineures npm du thème (configuration hebdomadaire commune)
- [ ] `ignore` Dependabot levé sur les paquets de la chaîne (`@dependabot unignore <paquet>`)
