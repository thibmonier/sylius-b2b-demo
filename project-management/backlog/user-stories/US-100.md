# US-100 — Les 403 expliqués et les menus inaccessibles masqués

> Epic : [EPIC-11](../epics/EPIC-11.md) · Persona : Paul · MoSCoW : **Should** · Points : **3** · Sprint : cible sprint 20 (replanifiée le 2026-10-21, repositionnement « recherche d'emploi »)
> Dépendances : audit fonctionnel D9

## Story

En tant que Paul (approbateur), je veux que les entrées de menu qui me sont interdites disparaissent et qu'un refus affiche un message explicite, afin de comprendre la gouvernance des rôles.

## Contexte

Les plafonds renvoient un 403 nu pour l'approbateur alors que le menu les propose. Un message « votre rôle ne permet pas cette action, demandez à votre administrateur » remplace la page nue.

## Critères d'acceptation

```gherkin
Fonctionnalité: Les 403 expliqués et les menus inaccessibles masqués

  Scénario: Menu filtré (nominal)
    Étant donné Paul connecté
    Quand il ouvre son espace
    Alors aucune entrée interdite n'est proposée

  Scénario: Message explicite (alternatif)
    Étant donné Paul ouvre directement une adresse interdite
    Quand la page répond
    Alors un message explique le rôle manquant et propose un retour

  Scénario: Aucune fuite d'information (erreur)
    Étant donné une ressource inexistante
    Quand elle est demandée
    Alors la réponse est un 404 sans détail du rôle
```
