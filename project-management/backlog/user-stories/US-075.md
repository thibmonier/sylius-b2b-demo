# US-075 — Connexion : comptes de démo en premier, groupés par société

> Epic : [EPIC-10](../epics/EPIC-10.md) · Persona : Nadia · MoSCoW : **Should** · Points : **2** · Sprint : cible sprint 14 (provisoire, planning au lancement du sprint)
> Dépendances : audit UX du 2026-10-18

## Story

En tant que Nadia, je veux voir les comptes de démo en premier sur la page de connexion, regroupés par société, afin d'entrer dans la démo en un clic sans lire une notice.

## Contexte

Le formulaire classique occupe le haut de la page et les comptes de démo sont dessous ; le code des identifiants est peu lisible (voir US-073). Les comptes sont groupés par société (Acme Industries, BigCorp, marchand).

## Critères d'acceptation

```gherkin
Fonctionnalité: Connexion : comptes de démo en premier, groupés par société

  Scénario: Comptes en tête, groupés (nominal)
    Étant donné la page de connexion en mode démo
    Quand elle est affichée
    Alors les comptes sont en premier, groupés par société, avec leur rôle

  Scénario: Connexion en un clic (alternatif)
    Étant donné un compte de démo affiché
    Quand le visiteur le choisit
    Alors il est connecté avec le rôle annoncé

  Scénario: Mode non démo (erreur)
    Étant donné l'environnement n'est pas une démo
    Quand la page de connexion est affichée
    Alors aucun compte de démo n'apparaît
```
