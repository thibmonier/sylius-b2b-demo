# US-244 — Copilote d'achat : installation dans la démo et captures du widget

> Epic : [EPIC-16](../epics/EPIC-16.md) · Persona : Claire (acheteuse, Acme Industries) ; Thibaut (démonstrateur) · MoSCoW : **Should** · Points : **3** · Sprint : sprint 38 · Statut : **ready-for-dev**
> Dépendances : US-211 (plugin `tmonier/sylius-b2b-sales-copilot-plugin` v0.1.0, soumis à Packagist par Thibaut)
> Origine : revue du sprint 37 et audits du 2026-10-30

## Story

En tant que Claire, je veux trouver le copilote d'achat dans mon compte sur la démo, afin d'essayer une demande enregistrée comme « état de mon panier ».

## Contexte

US-211 a livré le squelette du plugin (adaptateur rejoué, widget, garde d'accès par canal) sans l'installer dans la démo ; ses captures n'ont donc pas été faites. Cette story installe la v0.1.0, active le canal B2B dans `enabled_channels`, ajoute le plugin au catalogue de la vitrine et produit les captures FR et EN pour les README du plugin.

## Critères d'acceptation

```gherkin
Fonctionnalité: Copilote d'achat dans la démo

  Scénario: Widget dans le compte B2B (nominal)
    Étant donné Claire connectée sur le canal B2B
    Quand elle ouvre son tableau de bord
    Alors le widget du copilote est affiché

  Scénario: Demande enregistrée (alternatif)
    Étant donné le widget ouvert
    Quand Claire envoie « état de mon panier »
    Alors elle reçoit la réponse enregistrée

  Scénario: Canal particulier (alternatif)
    Étant donné Léa connectée sur le canal particulier
    Quand elle ouvre son compte
    Alors aucun widget n'est affiché

  Scénario: Demande non enregistrée (erreur)
    Étant donné une demande absente des cassettes
    Quand Claire l'envoie
    Alors elle voit le message « scénario non enregistré en démo »

  Scénario: Accessibilité (erreur évitée)
    Étant donné le tableau de bord avec le widget
    Quand pa11y l'audite au niveau AAA
    Alors aucune erreur n'est détectée
```
