# US-005 — CI GitHub Actions et tests de fumée

> Epic : [EPIC-01](../epics/EPIC-01.md) · Persona : Thibaut · MoSCoW : **Must** · Points : **3** · Sprint : 1
> Dépendances : US-002

## Story

En tant que Thibaut, je veux une CI qui construit l'image et vérifie les pages clés, afin de ne jamais déployer une démo cassée.

## Valeur

Garde-fou avant chaque déploiement.

## Critères d'acceptation

```gherkin
Fonctionnalité: CI GitHub Actions et tests de fumée

  Scénario: Pipeline
    Quand je pousse sur main
    Alors l'image est construite, les fixtures chargées et les pages clés (accueil, catalogue, fiche produit, panier, admin) répondent sans erreur
    Et le pipeline échoue sinon
```
