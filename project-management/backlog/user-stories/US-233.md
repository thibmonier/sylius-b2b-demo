# US-233 — Passeport numérique produit : pièces détachées compatibles liées à customer-asset-management

> Epic : [EPIC-19](../epics/EPIC-19.md) · Persona : Isabelle (administratrice) ; Claire (acheteuse) · MoSCoW : **Must** · Points : **3** · Sprint : sprint 36 (proposé, décision de Thibaut du 2026-10-28) · Statut : **backlog**
> Dépendances : US-230, plugin customer-asset-management (publié)

## Story

En tant que Claire, je veux voir les pièces détachées compatibles d'un équipement depuis son passeport, afin de commander la bonne pièce.

## Contexte

Lien optionnel (le DPP ne dépend pas du plugin) entre le passeport d'un produit et les pièces compatibles déclarées dans customer-asset-management : depuis la page publique et depuis la fiche d'un équipement du parc, un bloc « Pièces compatibles » renvoie vers les produits à commander.

Règles transverses de la feuille de route : voir [roadmap-innovation](../roadmap-innovation.md) (ton neutre, aucun détail de sécurité dans le dépôt public, aucune promesse réglementaire).

## Critères d'acceptation

```gherkin
Fonctionnalité: Passeport numérique produit : pièces détachées compatibles liées à customer-asset-management

  Scénario: Pièces affichées (nominal)
    Étant donné un équipement avec 3 pièces compatibles
    Quand Claire ouvre son passeport
    Alors les 3 pièces s'affichent avec lien vers leur fiche

  Scénario: Depuis le parc d'équipements (alternatif)
    Étant donné un équipement du parc d'Acme
    Quand Claire ouvre sa fiche
    Alors le lien vers le passeport et les pièces apparaît

  Scénario: Plugin parc absent (alternatif)
    Étant donné un projet sans customer-asset-management
    Quand la page publique s'affiche
    Alors le bloc est absent, sans erreur

  Scénario: Pièce retirée du catalogue (erreur)
    Étant donné une pièce non vendable
    Quand le bloc s'affiche
    Alors elle est listée comme indisponible, sans lien d'achat

  Scénario: Cloisonnement (erreur)
    Étant donné le parc d'une autre entreprise
    Quand Claire ouvre son passeport
    Alors aucune donnée de l'autre parc n'apparaît
```
