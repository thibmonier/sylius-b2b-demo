# US-027 — Simulateur d'outil d'achat

> Epic : [EPIC-07](../epics/EPIC-07.md) · Persona : Hugo · MoSCoW : **Should** · Points : **5** · Sprint : 5
> Dépendances : US-010

## Story

En tant que Hugo, je veux simuler Ariba ou SAP depuis la démo, afin de voir le PunchOut sans compte d'outil d'achat.

## Critères d'acceptation

```gherkin
Fonctionnalité: Simulateur d'outil d'achat

  Scénario: Aller-retour
    Quand je lance une session cXML ou OCI depuis le simulateur
    Alors j'arrive dans la boutique connecté comme l'acheteur, et le panier transféré s'affiche dans le simulateur
    Et je peux envoyer l'OrderRequest correspondant

  Scénario: Session OCI
    Quand je lance une session OCI
    Alors le panier est renvoyé via le HOOK_URL et affiché dans le simulateur

  Scénario: Commande créée
    Étant donné un panier transféré dans le simulateur
    Quand j'envoie l'OrderRequest
    Alors une commande est créée côté boutique

  Scénario: Hors mode démo
    Étant donné le mode démo désactivé
    Quand j'ouvre le simulateur
    Alors la page répond 404

  Scénario: Session invalide
    Quand j'ouvre le retour du simulateur avec une session expirée
    Alors un message clair s'affiche et aucune commande n'est créée

  Scénario: Panier vide
    Quand je renvoie un panier vide
    Alors l'envoi d'OrderRequest est refusé avec un message
```

## Notes

Adapté du simulateur de la TestApplication du plugin punchout.
