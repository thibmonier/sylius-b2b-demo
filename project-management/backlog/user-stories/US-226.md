# US-226 — Thème Industrie & Négoce : mode sombre optionnel en AAA

> Epic : [EPIC-18](../epics/EPIC-18.md) · Persona : Hugo (intégrateur Sylius) ; Nadia (responsable e-commerce B2B) · MoSCoW : **Should** · Points : **3** · Sprint : sprint 39 (proposé, décision de Thibaut du 2026-10-28) · Statut : **backlog**

## Story

En tant qu'utilisatrice qui travaille longtemps sur le site, je veux un mode sombre optionnel, afin de réduire la fatigue visuelle sans perdre en lisibilité.

## Contexte

Jeu de jetons sombre (US-222) activé par le réglage du système ou par un commutateur mémorisé. **Tous les contrastes atteignent le niveau AAA** (7:1 pour le texte normal). Pas de mode sombre par défaut : option.

Règles transverses de la feuille de route : voir [roadmap-innovation](../roadmap-innovation.md) (ton neutre, aucun détail de sécurité dans le dépôt public, aucune promesse réglementaire).
