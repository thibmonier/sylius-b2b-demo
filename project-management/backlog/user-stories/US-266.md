# US-266 — PHPUnit 13 sur les plugins sans abandonner PHP 8.2 et 8.3

> Epic : [EPIC-10](../epics/EPIC-10.md) · Persona : Thibaut · MoSCoW : **Should** · Points : **5** · Sprint : à planifier · Statut : **backlog**
> Origine : veille des versions du 2026-11-03 (26 PR Dependabot `phpunit/phpunit ^10.5 → ^13.4`, toutes rouges, fermées)

## Story

En tant que Thibaut, je veux que les plugins testent avec PHPUnit 13 quand PHP le permet, afin de rester au plus haut de la pile sans casser la matrice de compatibilité PHP 8.2 et 8.3.

## Contexte

Le 2026-11-03, Dependabot a ouvert la même PR sur 26 plugins : remplacer `phpunit/phpunit: ^10.5` par `^13.4`. Toutes échouent sur les lignes PHP 8.2 et 8.3 de la matrice : PHPUnit 13 exige PHP 8.4, PHPUnit 12 exige PHP 8.3. La démo, en PHP 8.5, est déjà sur PHPUnit 13.4.

Piste : contrainte élargie `^10.5 || ^11.5 || ^12.5 || ^13.4`, Composer choisissant la plus haute compatible par ligne. Elle impose un code de test compatible avec chaque version : attributs PHP au lieu des annotations, pas de `getMockForAbstractClass()`, `createStub()` pour les doublures sans attente, data providers statiques.

Les PR fermées portent la commande `@dependabot ignore this major version` : Dependabot ne reproposera pas la montée avant cette story.

## Critères d'acceptation

```gherkin
Fonctionnalité: PHPUnit 13 sur les plugins

  Scénario: Ligne PHP 8.4 ou plus (nominal)
    Étant donné un plugin dont la contrainte est élargie
    Quand le CI exécute la ligne PHP 8.4 de la matrice
    Alors PHPUnit 13 est installé et la suite est verte

  Scénario: Ligne PHP 8.2 (alternatif)
    Étant donné le même plugin
    Quand le CI exécute la ligne PHP 8.2
    Alors PHPUnit 11 est installé et la suite est verte, avec le même nombre de tests

  Scénario: Ligne PHP 8.3 (alternatif)
    Quand le CI exécute la ligne PHP 8.3
    Alors PHPUnit 12 est installé et la suite est verte

  Scénario: Code de test incompatible (erreur)
    Étant donné un test qui utilise une API retirée de PHPUnit 12
    Quand la ligne PHP 8.4 s'exécute
    Alors le CI échoue sur ce test, qui est réécrit avec l'API commune

  Scénario: Dépréciations (erreur évitée)
    Quand la suite tourne sous PHPUnit 13
    Alors aucune dépréciation PHPUnit n'est signalée
```

## Definition of Done

- [ ] Contrainte élargie et tests adaptés sur les 26 plugins (une PR par dépôt, CI vert sur toute la matrice)
- [ ] Le nombre de tests (« Tests: N ») est identique entre les lignes PHP 8.2 et 8.4 d'un même plugin
- [ ] `ignore` Dependabot levé : la prochaine montée PHPUnit est de nouveau proposée
