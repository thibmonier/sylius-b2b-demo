# US-194 — Logo de l'auteur dans le pied de page

> Epic : [EPIC-12](../epics/EPIC-12.md) · Persona : Camille (recruteuse IT) · MoSCoW : **Should** · Points : **1** · Sprint : **sprint 27** ([tâches](../../sprints/sprint-27-fiche-produit-et-erp-fictif/tasks/US-194-tasks.md))
> Origine : demande de Thibaut du 2026-10-24, ajoutée au sprint 27 ; réalisée par w185

## Story

En tant que visiteur de la démo, je veux voir l'identité visuelle de l'auteur près de « Réalisé par Thibaut Monier » dans le pied de page, afin de relier la démo à son profil Marketplace Sylius.

## Contexte

Le pied de page affiche déjà la mention « Réalisé par Thibaut Monier » (`templates/shop/theme_b2b/footer_demo.html.twig`). Le logo s'y ajoute, purement décoratif : le nom de l'auteur reste porté par le texte.

### Validation INVEST

- [x] Independent / Negotiable / Valuable / Estimable ≈ 1 h / Sized 1 / Testable

## Critères d'acceptation

```gherkin
Fonctionnalité: Logo de l'auteur dans le pied de page

  Scénario: Logo près de la mention de l'auteur (nominal)
    Étant donné un visiteur sur une page de la démo
    Quand il lit le pied de page
    Alors le logo de l'auteur apparaît près de « Réalisé par Thibaut Monier »

  Scénario: Image décorative (alternatif)
    Étant donné le logo dans le pied de page
    Quand un lecteur d'écran parcourt la page
    Alors l'image a un `alt` vide et la mention textuelle porte le nom de l'auteur

  Scénario: Dimensions déclarées (alternatif)
    Étant donné le logo dans le pied de page
    Quand la page se charge
    Alors l'image déclare `width` et `height`, sans décalage de mise en page

  Scénario: Téléphone (erreur)
    Étant donné le pied de page affiché à 360 px
    Quand la mesure s'exécute
    Alors aucun élément ne dépasse la largeur de l'écran

  Scénario: Fichier trop lourd (erreur)
    Étant donné le fichier du logo
    Quand le test de budget s'exécute
    Alors un test échoue si le fichier dépasse 8 Ko
```

## Definition of Done

- [ ] Chaque scénario relié à un test ou à une preuve
- [ ] Commit de tests rouges seul, cité dans la PR
- [ ] pa11y WCAG2AAA et 360 px sur une page en production, mesures consignées le jour du déploiement
- [ ] PHPStan max (dépôt entier), ECS et Rector verts
