# US-057 : Plugin équipements : parc du client dans l'espace client (CRUD)

> Epic : [EPIC-14](../epics/EPIC-14.md) · Persona : Claire (acheteuse d'Acme Industries) · MoSCoW : **Should** · Points : **5** · Sprint : 21
> Dépendances : US-056 (modèles d'équipement) ; MMF avec US-056 et US-058 ; US-058 en dépend (parc non vide)

## Story

En tant que Claire, acheteuse d'une entreprise de transport, je veux déclarer, modifier et supprimer les machines de mon parc (modèle d'équipement, libellé, plaque ou numéro de série) dans mon espace client, afin que le catalogue sache de quels équipements je m'occupe.

## Contexte

Deuxième tranche du plugin `tmonier/sylius-customer-asset-management-plugin`. Sources : `SPEC.md` §2, §4 et §7, ADR-0001 (décisions 1, 3, 5 et 6).

Règles figées par la spécification et l'ADR :
- table `customer_asset` : identifiant **UUID**, client propriétaire, modèle d'équipement, libellé libre, identifiant (plaque ou numéro de série) ;
- une page « Mon matériel » dans le compte : liste, ajout, modification, suppression ;
- le propriétaire est le client qui a déclaré la machine ; un client ne voit et ne modifie **que son parc** ; un identifiant étranger ou inconnu répond **404**, jamais 403 (pas de fuite d'existence) ; contrôle serveur par un **voter** sur chaque route ;
- si `tmonier/sylius-company-accounts-plugin` est installé, le voter accorde aussi l'accès aux membres de l'entreprise du propriétaire ; le plugin fonctionne sans (dépendance optionnelle : `require-dev` et `suggest` seulement) ;
- suppression des machines avec le client (`ON DELETE CASCADE` en base, cascade Doctrine) ;
- toute saisie est validée côté serveur.

**Données personnelles** (`SPEC.md` §7) : une plaque ou un numéro de série peut identifier une personne (entrepreneur individuel). Ces valeurs ne sont jamais journalisées ni placées dans une URL ; elles sont supprimées avec le compte client. La limitation du débit à la création est laissée à l'application et documentée dans le README.

**Hors périmètre** : import en masse du parc, maintenance et interventions, télématique, filtre du catalogue (US-058).

### Les 3 C

- **Carte** : la story ci-dessus.
- **Conversation** : un modèle d'équipement utilisé par au moins un parc ne peut plus être supprimé en administration (message explicite) ; c'est la garde annoncée à l'US-056, ajoutée ici car elle dépend de `customer_asset`. Limite proposée : 50 machines par client, pour borner la requête du filtre d'US-058 (à confirmer à l'implémentation).
- **Confirmation** : les scénarios Gherkin ci-dessous.

## Versions et publication

- **Versions supportées** : identiques à US-056 (PHP 8.2 à 8.5, Symfony `^6.4 || ^7.4 || ^8.0`, Sylius `~2.3.0`, MySQL 8.4, MariaDB 11.4, PostgreSQL 17). Vérifier en particulier `ON DELETE CASCADE` sur les trois bases.
- **Impact de version** : 0.1.0 (nouveau paquet) ; aucune rupture. Le voter lit company-accounts par détection à l'exécution : aucune contrainte de version sur ce plugin.

## Critères d'acceptation

```gherkin
Fonctionnalité: Parc d'équipements du client

  Scénario: Déclarer une machine (nominal)
    Étant donné que Claire est connectée et qu'un modèle « Camion Modèle X » existe
    Quand elle ajoute une machine de modèle « Camion Modèle X », de libellé « Camion de Lyon » et d'immatriculation « AB-123-CD »
    Alors la machine apparaît dans « Mon matériel » avec ces trois valeurs
    Et son adresse contient un UUID, sans la plaque

  Scénario: Modifier puis supprimer une machine (alternatif)
    Étant donné une machine « Camion de Lyon » dans le parc de Claire
    Quand elle change le libellé en « Camion de Grenoble », enregistre, puis supprime la machine et confirme
    Alors la liste a affiché « Camion de Grenoble » après la modification
    Et la liste ne contient plus la machine après la suppression

  Scénario: Parc partagé avec l'entreprise (alternatif)
    Étant donné que le plugin company-accounts est installé et que Claire et Paul sont membres d'Acme Industries
    Quand Paul ouvre « Mon matériel »
    Alors il voit les machines de Claire et peut les modifier

  Scénario: Plugin company-accounts absent (alternatif)
    Étant donné une boutique sans le plugin company-accounts
    Quand Paul ouvre « Mon matériel »
    Alors il ne voit que ses propres machines, sans erreur

  Scénario: Suppression du compte client (alternatif)
    Étant donné un client avec 3 machines
    Quand son compte est supprimé
    Alors ses 3 machines sont supprimées avec lui

  Scénario: Machine d'un autre client (erreur)
    Étant donné une machine appartenant à un client d'une autre entreprise
    Quand Claire ouvre, modifie ou supprime cette machine par son UUID
    Alors le serveur répond 404 dans les trois cas, comme pour un UUID inexistant
    Et la machine n'est pas modifiée

  Scénario: Saisie invalide (erreur)
    Étant donné le formulaire d'ajout d'une machine
    Quand Claire envoie un identifiant vide, de plus de 40 caractères ou contenant des caractères de contrôle, ou un modèle inexistant
    Alors le formulaire est refusé avec un message par champ en erreur et aucune machine n'est créée

  Scénario: Visiteur non connecté (erreur)
    Étant donné un visiteur non connecté
    Quand il ouvre « Mon matériel »
    Alors il est redirigé vers la connexion et aucune donnée de parc n'est affichée

  Scénario: Modèle utilisé par un parc (erreur)
    Étant donné un modèle « Camion Modèle X » utilisé par 2 machines de clients
    Quand Sophie tente de le supprimer en administration
    Alors la suppression est refusée avec un message indiquant que 2 machines l'utilisent
```
