# US-017 — Badges de plugin dans l'admin

> Epic : [EPIC-03](../epics/EPIC-03.md) · Persona : Hugo · MoSCoW : **Must** · Points : **3** · Sprint : 4
> Dépendances : US-016

## Story

En tant que Hugo, je veux les mêmes badges dans l'admin, afin d'identifier les apports back-office.

## Critères d'acceptation

```gherkin
Fonctionnalité: Badges de plugin dans l'admin

  Scénario: Badge admin (nominal)
    Quand Sophie consulte une fiche commande, client ou produit
    Alors les blocs des plugins (timeline, audit, approbation, Factur-X…) portent un badge

  Scénario: Accessibilité clavier (alternatif)
    Quand je navigue au clavier sur un badge admin
    Alors l'infobulle « Plugin tmonier/… » s'affiche au focus et le lien vers le plugin est activable

  Scénario: Cohérence avec le shop (alternatif)
    Quand un plugin a un badge dans le shop et dans l'admin
    Alors les deux badges utilisent le même registre, nom et lien

  Scénario: Bloc natif Sylius (erreur)
    Quand je consulte un bloc natif Sylius
    Alors aucun badge n'est ajouté

  Scénario: Plugin non installé (erreur)
    Quand un plugin du registre admin n'est pas activé
    Alors aucun badge ni bloc vide n'est rendu et la fiche s'affiche sans erreur
```
