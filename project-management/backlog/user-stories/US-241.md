# US-241 — Passeport numérique produit : installation dans la démo, captures et audit pa11y AAA

> Epic : [EPIC-19](../epics/EPIC-19.md) · Persona : Claire (cliente) ; Thibaut (démonstrateur) · MoSCoW : **Must** · Points : **2** · Sprint : sprint 37 · Statut : **backlog**
> Dépendances : US-231 (plugin passeport v0.1.0)

## Story

En tant que Claire, je veux consulter le passeport numérique d'un produit depuis la démo B2B, afin de connaître son origine, sa recyclabilité et comment le réparer.

## Contexte

Installation du plugin `tmonier/sylius-digital-product-passport-plugin` ^0.1 dans la démo, configuration de passeports de démonstration pour quelques produits du catalogue, capture de la page publique d'un passeport (française et anglaise) pour les README EN et FR du plugin passeport, et audit pa11y AAA de la page publique (reporté d'US-231 au sprint 36).

Règles transverses de la feuille de route : voir [roadmap-innovation](../roadmap-innovation.md) (ton neutre, aucun détail de sécurité dans le dépôt public, aucune promesse réglementaire).
