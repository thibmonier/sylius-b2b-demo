# US-234 — Passeport numérique produit : lien optionnel du passeport dans la facture Factur-X

> Epic : [EPIC-19](../epics/EPIC-19.md) · Persona : Isabelle (administratrice) ; Sophie (back-office) · MoSCoW : **Could** · Points : **3** · Sprint : non planifiée (proposé, décision de Thibaut du 2026-10-28) · Statut : **backlog**
> Dépendances : US-231, plugin facturx (publié)

## Story

En tant que marchand, je veux que la facture Factur-X indique le lien du passeport des produits facturés, afin de relier le justificatif et la fiche produit.

## Contexte

Option du plugin facturx : un champ de note ou de référence documentaire contient le lien du passeport, désactivé par défaut. Pas de modification du profil Factur-X ni de promesse de valeur réglementaire.

Règles transverses de la feuille de route : voir [roadmap-innovation](../roadmap-innovation.md) (ton neutre, aucun détail de sécurité dans le dépôt public, aucune promesse réglementaire).
