# US-002 — Image Docker FrankenPHP multi-stage

> Epic : [EPIC-01](../epics/EPIC-01.md) · Persona : Thibaut · MoSCoW : **Must** · Points : **5** · Sprint : 1
> Dépendances : US-001

## Story

En tant que Thibaut, je veux une image Docker FrankenPHP (Caddy), afin de servir la démo de façon performante et identique partout.

## Valeur

Une seule image pour le local, la CI et Railway.

## Critères d'acceptation

```gherkin
Fonctionnalité: Image Docker FrankenPHP multi-stage

  Scénario: Build reproductible
    Quand je construis l'image
    Alors elle contient PHP 8.4 (intl, gd, zip, pdo_mysql, Argon2id), wkhtmltopdf, les assets compilés et le cache préchauffé
    Et Node n'est pas présent dans l'image finale

  Scénario: Démarrage
    Étant donné l'image et une base MySQL
    Quand le conteneur démarre
    Alors la page d'accueil répond 200 en HTTPS local
    Et le healthcheck `/healthz` répond 200
```

## Notes

Base dunglas/symfony-docker ; trusted proxies ; utilisateur non root.
