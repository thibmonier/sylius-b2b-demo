# US-030 — Guide de connexion MCP

> Epic : [EPIC-07](../epics/EPIC-07.md) · Persona : Hugo · MoSCoW : **Could** · Points : **2** · Sprint : 8
> Dépendances : US-009

## Story

En tant que Hugo, je veux connecter Claude à la démo, afin de commander par conversation.

## Critères d'acceptation

```gherkin
Fonctionnalité: Guide de connexion MCP

  Scénario: Connexion
    Quand je suis le guide de la page MCP
    Alors je connecte Claude au compte de Claire (OAuth) et liste ses commandes

  Scénario: Guide en anglais
    Étant donné la page MCP affichée en anglais
    Quand je suis le guide
    Alors les étapes, le bloc de configuration copiable et les liens sont identiques à la version française

  Scénario: Compte non approuvé
    Étant donné un compte de démo en attente ou rejeté
    Quand je tente de le connecter par OAuth ou d'appeler /_mcp
    Alors l'accès est refusé (403 access_denied) et le guide l'indique

  Scénario: Jeton absent ou expiré
    Étant donné un jeton d'accès absent ou expiré
    Quand l'assistant appelle /_mcp
    Alors la réponse est un refus d'authentification, sans commande exposée, et le guide explique comment se reconnecter

  Scénario: Hôte non autorisé
    Étant donné le garde sortant du serveur MCP
    Quand une requête du client MCP vise un hôte hors liste d'autorisation
    Alors elle est refusée et aucune donnée n'est envoyée à cet hôte
```
