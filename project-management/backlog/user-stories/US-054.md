# US-054 — Plugin parc d'équipements client, tranche 1

> Epic : [EPIC-07](../epics/EPIC-07.md) · Persona : Thibaut · MoSCoW : **Could** · Points : **4** (tranche 1) · Sprint : 12
> Dépendances : aucune ; suite en backlog (US-056 à US-060)

## Story

En tant que Thibaut, je veux cadrer le plugin OSS `tmonier/sylius-customer-asset-management-plugin` (spec, ADR, chevauchement avec Sylius Plus) et en poser le socle qualité, afin de décider de le construire, de le publier et de le promouvoir (ou non) avant d'y investir le développement fonctionnel.

## Contexte

Besoin B2B (industrie, bâtiment) : un client déclare son parc dans son espace client (« Camion Modèle X, immatriculation AB-123-CD ») ; le catalogue peut être filtré pour n'afficher que les pièces compatibles avec ses équipements. Le plugin vit dans un dépôt séparé, `/Users/tmonier/Projects/sylius_plugins/sylius-customer-asset-management-plugin`, qui n'existe pas encore ([ADR-0006](../../../docs/adr/0006-nouveaux-plugins-publies-separement.md)). Le plugin de référence est `sylius-channel-access-plugin` (le plus récent). Politique de communication : si Sylius Plus couvre déjà le besoin, le plugin n'est pas promu.

## Périmètre

- **Tranche 1 (ce sprint)** : mini-spec, ADR-0001, vérification de chevauchement avec Sylius Plus (verdict et sources), skeleton SyliusLabs, socle qualité (ECS, PHPStan max, Rector, tests, CI multi-versions).
- **Publication (décision du 2026-10-17)** : dépôt GitHub public et publication sur Packagist, comme les autres plugins. Claude crée le dépôt (T-054-04) et pose le tag après confirmation explicite ; l'utilisateur soumet lui-même le paquet à Packagist (US-059).
- **Reporté en backlog** (`.bmad/sprint-status.yaml`, section `backlog:`) : US-056 modèles d'équipement liés aux variantes (admin), US-057 parc du client (espace client, CRUD), US-058 filtre « pièces compatibles », US-059 publication (tag, Packagist), US-060 intégration à la démo (données de démo, entrée dans `config/demo/plugins.yaml`), seulement si la tranche 1 est terminée.
- Hors périmètre : toute entité, tout écran, tout filtre ; toute promotion.

```gherkin
    Quand le sprint se termine
    Alors aucun dépôt GitHub n'est créé, aucun tag posé, aucun paquet soumis à Packagist
    Et T-054-04 reste ouverte
```
