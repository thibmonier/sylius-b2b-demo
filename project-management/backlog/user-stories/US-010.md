# US-010 — Données des plugins cohérentes

> Epic : [EPIC-02](../epics/EPIC-02.md) · Persona : Nadia · MoSCoW : **Must** · Points : **8** · Sprint : 2
> Dépendances : US-009

## Story

En tant que Nadia, je veux que les données de chaque plugin forment des parcours cohérents, afin que les scénarios fonctionnent bout à bout.

## Valeur

Corrige I4, I5, I6.

## Critères d'acceptation

```gherkin
Fonctionnalité: Données des plugins cohérentes

  Scénario: Cohérence
    Quand les fixtures sont chargées
    Alors le crédit commercial est porté par l'entreprise, les limites d'approbation sont adaptées aux prix par paliers, et les devis, palettes, GPSR, acheteurs PunchOut et suggestions IA existent
    Et les priorités de fixtures sont explicites et distinctes

  Scénario: Scénario approbation
    Étant donné Claire connectée
    Quand elle commande au-delà de sa limite
    Alors la commande part en validation chez Paul

  Scénario d'erreur: Priorité de fixture dupliquée entre plugins
    Étant donné deux fichiers de fixture de plugins distincts déclarant la même valeur de priorité de chargement
    Quand les fixtures sont exécutées
    Alors la commande se termine avec un code de sortie non nul
    Et le journal d'erreur identifie les deux fixtures en conflit avec leurs noms et priorités respectives
    Et aucune donnée partielle issue des fixtures en conflit n'est persistée

  Scénario d'erreur: Donnée inter-plugin incohérente détectée
    Étant donné des fixtures où un identifiant référencé par le plugin de devis n'existe pas dans les données du plugin entreprise
    Quand les fixtures sont exécutées avec la vérification de cohérence activée
    Alors la commande se termine avec un code de sortie non nul
    Et le journal d'erreur indique la référence manquante, le plugin source et le plugin cible attendu
```

## Notes

Les fixtures des plugins ne sont reprises que si elles sont cohérentes, sinon elles sont remplacées.
